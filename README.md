# Inbody (React)

## 프로젝트 소개  
사용자의 건강 데이터를 직관적으로 확인할 수 있는 React SPA로, 컴포넌트 재사용성과 유지보수성을 고려해 개발했습니다.

## 주요 기능  
- 사용자 맞춤형 건강 데이터 시각화  
- Redux 상태 관리 도입  
- Chart.js 차트 활용  
- 반응형 UI 구현 및 최적화

## 사용 기술  
React, Redux, Chart.js, CSS Modules
